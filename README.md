# Internship_Telecom

Codes:
- **TW_ab**: defines a class to solve the max of Bell Inequalities in the TW, with two Observers: Alice and Bob
- **TW_abe**: defines a class to solve the max of Bell Inequalities in the TW, with three Observers: Alice, Bob and Eve
- **TW_cb_noTW_e**: defines a class to solve the max of Bell Inequalities in the TW, with three Observers: Alice, Bob and Eve. Alice and Bob
  have the constraints of TW, but Eve doesn't. It is possible to add the constraint of Bound Randomness.
